# Projeto Next.js

Este é um projeto desenvolvido com [Next.js](https://nextjs.org), criado utilizando a ferramenta [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

 🚀 Como começar

Primeiro, instale as dependências do projeto:

```bash
npm install
```

Em seguida, inicie o servidor de desenvolvimento:

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para visualizar o projeto.

Você pode começar a editar a página principal modificando o arquivo `app/page.tsx`.

As alterações serão atualizadas automaticamente no navegador enquanto você desenvolve.

 🛠️ Tecnologias utilizadas

- **Next.js:** Framework React para desenvolvimento de aplicações web.
- **React:** Biblioteca JavaScript para construção de interfaces.
- **TypeScript:** Linguagem baseada em JavaScript com tipagem estática.
- **Geist:** Família de fontes otimizada para aplicações modernas.

 🎨 Fontes e otimização

Este projeto utiliza [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) para otimizar e carregar automaticamente a fonte [Geist](https://vercel.com/font), desenvolvida pela Vercel.

Essa funcionalidade contribui para melhorar o desempenho e a experiência dos usuários.

🌐 Publicação na Vercel

Uma das maneiras mais simples de publicar sua aplicação Next.js é utilizando a [Vercel](https://vercel.com/new), plataforma desenvolvida pelos criadores do Next.js.

Para publicar seu projeto:

1. Envie o código para um repositório no GitHub.
2. Acesse a plataforma Vercel.
3. Conecte sua conta do GitHub.
4. Importe o repositório do projeto.
5. Configure as variáveis de ambiente, caso necessário.
6. Clique em **Deploy** para publicar sua aplicação.

Para mais informações, consulte a [documentação oficial de implantação do Next.js](https://nextjs.org/docs/app/building-your-application/deploying).
